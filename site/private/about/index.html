1. Overview & Philosophy

Zixuan "Tomi" Yang (born 2008), known online as TomiWebPro, is an 18-year-old developer and systems engineering student currently studying Information Engineering at the Technical University of Munich (TUM) on the Heilbronn campus in Germany[1].

Yang's engineering work centers on high-leverage software primitives: multi-autonomous agent orchestration harnesses, baseboard management controller (BMC) automation for datacenter server racks, DPI-resistant mesh networking, and self-hosted containerized infrastructure. His design philosophy favors zero-dependency, local-first architectures, strict protocol transparency, and automated feedback loops over marketing abstractions.

3. Systems, AI & Engineering Work

Yang has initiated, authored, or co-maintained 8 standalone open-source software projects across artificial intelligence, mesh networking, hardware interfaces, and utilities:

Cognithor (Multi-Autonomous Agent Harness)

In January 2026, inspired by early agent frameworks, Yang co-developed Cognithor with a German collaborator. Reaching over 100,000 lines of modular Python, the system incorporates long-term episodic memory, computer-use automation, and multi-agent coordination. Notably, the framework enabled open-weights Qwen 30B to solve approximately 30% of ARC-AGI-3 benchmark tasks, outperforming published Claude Opus 4.7 approaches[3]. The project earned 150+ organic GitHub stars.
Explore Cognithor Project Page →

Stealthscale (Undetectable Mesh Networking)

Developed in October 2026 after experiencing severe firewall restrictions during travel to China, Stealthscale builds upon Tailscale and Headscale primitives. It encapsulates WireGuard packets within authentic TLS 1.3/HTTP/2 frames, adding randomized padding and timing jitter to defeat deep packet inspection (DPI) and traffic analysis.
Explore Stealthscale Project Page →

OpenBMCUI (Redfish & BMC Automation)

In September 2026, following visits to Compal's server testing laboratory in Taiwan, Yang created OpenBMCUI. The tool integrates DMTF Redfish REST APIs with an LLM orchestration engine to automate bare-metal server operating system installation, driver compilation, and InfiniBand bandwidth qualification.
Explore OpenBMCUI Project Page →

StudyKing (Adaptive Learning Assistant)

Launched in June 2026 following IB exams, StudyKing explores how large language models can provide 1-on-1 tutoring dynamics at zero marginal cost. It decomposes university STEM syllabi into mastery graphs and generates adaptive practice exercises.
Explore StudyKing Project Page →

ECTS Tracker (Local-First Flutter Application)

Built in November 2026 for TUM students, ECTS Tracker is a local-first mobile and desktop application written in Flutter (Dart) using Riverpod for reactive state management and Drift (SQLite) for zero-latency local persistence. It translates European Credit Transfer System (ECTS) credit quotas into daily and weekly study-hour pacing benchmarks.
Explore ECTS Tracker Project Page →

PChess (Stockfish Engine & LLM Coach)

Developed as Yang's IB Computer Science Internal Assessment (earning a Grade 7), PChess uses Stockfish to identify critical tactical swings in PGN game logs, then prompts an LLM coach to explain the conceptual positional motifs rather than merely displaying engine lines.
Explore PChess Project Page →

NIQE Modernized Fork

Authored in March 2025 for his IB Extended Essay, this project upgraded the 2014 MATLAB/Python Natural Image Quality Evaluator to modern Python 3.11+ and OpenCV, using Natural Scene Statistics (NSS) to evaluate visual fidelity in NVIDIA DLSS vs AMD FSR upscaling.
Explore NIQE Fork Project Page →

ActiveLearnBypass

Created in June 2024, this concurrent Python tool automated parallel retrieval of unauthenticated high-resolution textbook page images and losslessly compiled them into offline PDFs.
Explore ActiveLearnBypass Project Page →
