Building Cognithor: Lessons from a 100k-Line Agent Framework & ARC-AGI-3

In January 2026, inspired by early agent frameworks like OpenClaw, my collaborator (a fellow developer based in Germany) and I asked a straightforward question: What does an agent architecture need to look like to autonomously solve reasoning problems that trip up frontier closed models?

With our International Baccalaureate exams looming in May, we didn't have years to write every single line manually. Instead, we heavily leveraged Claude 3.5 Sonnet to scaffold, test, and refactor our codebase. Within weeks, we shipped a production-ready harness that quickly exceeded 100,000 lines of modular Python code.

The Benchmark Challenge: ARC-AGI-3

The ARC (Abstraction and Reasoning Corpus) benchmark is designed specifically to test general reasoning without relying on memorization. Each task consists of input/output 2D color grids demonstrating an unknown transformation rule (e.g., gravity, occlusion, raycasting, topological filling). The agent must deduce the rule and transform a novel test input grid.

When evaluating frontier models zero-shot, even massive models struggle because the output space is combinatorial and unforgiving — a single misplaced pixel marks the entire task as failed.

Our Solution: The Code Synthesis & Verification Loop

Instead of prompting the LLM to directly output a matrix of numbers, Cognithor employs a hierarchical agent pipeline:

  1. Decomposer: Analyzes the train pairs and verbalizes visual transformation hypotheses in natural language.
  2. Programmer Agent: Translates those hypotheses into standalone Python functions that transform numpy.ndarray inputs to outputs.
  3. Sandbox Runner: Executes the candidate function against all provided training examples in an isolated Docker container.
  4. Verifier & Critic: If the code fails on even one example, diffs are computed, error traces are formatted into visual ASCII grids, and the programmer agent is guided to self-correct.

Results & Impact

Equipped with this harness, open-weights Qwen 30B achieved approximately 30% accuracy on ARC-AGI-3. Crucially, this outperformed published benchmark baselines achieved by Claude with Opus 4.7 operating under standard agent harnesses. It demonstrated a core truth of modern AI engineering: deterministic verification and feedback loops matter as much as base model size.

The project gained organic traction, crossing 150 GitHub stars without marketing, and its architectural lessons now form the foundation of our work on autonomous tool execution.
