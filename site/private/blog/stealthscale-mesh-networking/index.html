Designing Stealthscale: Obfuscating Mesh Network Traffic Against DPI

Published: Oct 2026 • By Tomi Yang • Tags: Mesh Networking, DPI, WireGuard, Go

Modern mesh VPNs like Tailscale and WireGuard have transformed personal infrastructure. The ability to directly connect your laptop, smartphone, and home hypervisors over encrypted peer-to-peer links without opening insecure inbound firewall ports feels like magic.

However, that magic breaks down when you enter environments with active adversarial network monitoring. During a trip to China after finishing high school, I witnessed firsthand how modern Deep Packet Inspection (DPI) handles standard VPN protocols. Even when running custom ports, WireGuard's 148-byte initial handshake packet, constant entropy distribution, and deterministic packet size increments make it an easy target for automated throttling or immediate TCP/UDP resets.

The Problem with Conventional VPNs

Commercial anti-censorship protocols (Shadowsocks, V2Ray, Xray) work well for web proxies, but they do not provide a native mesh overlay network. You lose peer-to-peer direct routing, automatic DNS resolution, split-tunneling, and multi-node cluster interconnection.

I wanted the best of both worlds: the seamless mesh topology of Tailscale/Headscale combined with protocol-level undetectability. That was the inspiration for Stealthscale.

How Stealthscale Evades Detection

Stealthscale operates by interposing a custom framing layer between the virtual TUN interface and the network transport:

  • True TLS 1.3 Handshake Mimicry: Rather than sending raw encrypted UDP packets, traffic is encapsulated in standard TLS 1.3 records terminating at a valid domain name with authentic SSL certificates. Middleboxes see normal HTTPS browser connections.
  • Padding & Packet Entropy Shaping: Encrypted payloads naturally have high Shannon entropy. Stealthscale injects randomized pseudo-random padding chunks and introduces subtle timing jitter to replicate the bursty signature of modern web browsing (e.g. streaming, web assets).
  • Multiplexed HTTP/2 & WebSocket Framing: Connections use real HTTP/2 binary framing. If an active DPI probe tests the endpoint with a fake request, the server responds with a legitimate static website fallback.

Decentralized Headscale Control Plane

To prevent central shutdown and eliminate telemetry leakage, Stealthscale is designed around a self-hosted Headscale control plane. Nodes register via public key cryptography, discover peers via a stealth STUN relay, and negotiate direct connections wherever possible.
