Problem & Motivation

While studying chess to improve competitive play, I grew frustrated with commercial platforms like Chess.com that restrict daily tactical puzzle access behind subscriptions. Furthermore, traditional chess software suffers from a major pedagogical flaw: engines give you a raw evaluation (e.g. +3.2 (Nf3)) without explaining why a candidate move is strong or what underlying tactical motif makes the opponent's reply ineffective.

I created PChess to solve both problems: generating infinite tactical puzzles from my own game PGN records using a local Stockfish binary, followed by an interactive LLM coach that explains strategic concepts in plain English.

Architecture & Implementation

pchess-engine-loop.txt 
[INPUT: USER PGN RECORD]
          |
          v
[STOCKFISH ENGINE PARSER (depth: 18+)]
  - Evaluates centipawn swings (|Δeval| > 180)
  - Filters out unforced trivial blunders
  - Extracts only positions with unique tactical solutions
          |
          v
[INTERACTIVE PUZZLE BOARD]
  - User plays candidate moves
  - If incorrect: allows retrying without revealing the solution
          |
          v
[LLM CONVERSATIONAL COACH]
  - Context: FEN string + Engine variation tree + tactical theme tags
  - Generates human-like explanation: "White exploits the pinned f6-knight..."
