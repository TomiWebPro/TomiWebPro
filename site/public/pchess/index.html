Problem & Motivation

While learning competitive chess, Tomi grew frustrated with commercial platforms like Chess.com restricting daily puzzle access behind subscriptions. More critically, standard chess software suffers from a major pedagogical flaw: engines output raw numerical evaluations (e.g. +3.2 (Nf3)) without explaining why a candidate move is decisive or what underlying tactical motif makes the opponent's reply ineffective.

PChess was engineered to solve both problems: generating infinite tactical puzzles from raw PGN game records using a local Stockfish engine, paired with a conversational LLM coach that explains strategic motifs in plain English.

Architecture & Evaluation

[STOCKFISH ENGINE PARSER (depth: 18+)]
  - Evaluates centipawn swings (|Δeval| > 180)
  - Filters out unforced trivial blunders
  - Extracts only positions with unique tactical solutions

[INTERACTIVE PUZZLE BOARD]
  - User plays candidate moves
  - If incorrect: allows retrying without revealing the solution

[LLM CONVERSATIONAL COACH]
  - Context: FEN string + Engine variation tree + tactical theme tags
  - Generates human-like explanation: "White exploits the pinned f6-knight..."
