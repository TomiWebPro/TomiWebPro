Executive Summary

Inspired by early open agent releases such as OpenClaw, Cognithor was designed to explore how far autonomous agent architectures can go when equipped with structured reasoning, deep tool execution, and long-term memory. Developed in collaboration with a German software engineer under tight schedules leading up to the May 2026 IB examinations, the project was scaled rapidly through AI-assisted development workflows.

Cognithor is an enterprise-grade agent runtime featuring self-healing execution loops, computer-use capabilities (mouse, keyboard, terminal, browser), long-term episodic vector memory, and strict GDPR security sandboxing.

Key Engineering Innovations

1. Autonomous Subagent Swarms: A hierarchical supervisor agent delegates subtasks to specialized worker agents with scoped permissions, isolating failures without crashing the entire run.

2. Reasoning-Guided Code Synthesis: For abstract visual grid tasks (ARC-AGI-3), the agent deduces transformations into candidate Python functions, runs them in Docker sandboxes, and verifies the diffs before submitting.

3. Episodic Memory Store: Indexes previous task solutions and error traces in vector stores, preventing redundant or cyclic exploration paths.

ARC-AGI-3 Benchmark Breakthrough

The ARC (Abstraction and Reasoning Corpus) benchmark is widely considered the gold standard for evaluating general reasoning in AI. On the third generation of the benchmark (ARC-AGI-3), standard zero-shot models perform poorly.

By plugging open-weights Qwen 30B into Cognithor's multi-agent code-generation and visual hypothesis verification pipeline, the framework successfully solved approximately 30% of ARC-AGI-3 tasks. This notably surpassed existing approaches from Claude with Opus 4.7, proving that an engineered agent harness and deterministic verification loop can dramatically amplify reasoning performance over raw model parameter scale.
