Executive Summary

Inspired by early open agent releases such as OpenClaw, Cognithor was designed to explore how far autonomous agent architectures can go when equipped with structured reasoning, deep tool execution, and long-term memory. Developed in collaboration with a German software engineer under tight schedules leading up to the May 2026 IB examinations, the project was scaled rapidly through AI-assisted development workflows.

Cognithor is not just a chatbot wrapper: it is an enterprise-grade agent runtime with self-healing execution loops, computer-use capabilities (mouse, keyboard, terminal, browser), long-term vector memory, and strict GDPR security sandboxing.

Key Engineering Innovations

1. Autonomous Subagent Swarms: A hierarchical supervisor agent delegates subtasks to specialized worker agents with scoped permissions, isolating failures without crashing the entire run.

2. Reasoning-Guided Hypothesis Generation: For abstract tasks like ARC-AGI-3, agents do not guess pixel answers directly. Instead, they formulate symbolic hypotheses, generate Python test programs, run them in sandboxes, and inspect the test grid output before committing.

3. Long-Term Cross-Session Memory: An episodic memory store indexes previous task solutions and runtime errors, allowing agents to avoid repeating failed exploration paths.

ARC-AGI-3 Benchmark Breakthrough

The ARC (Abstraction and Reasoning Corpus) benchmark is widely considered one of the hardest tests of general reasoning in AI. On the third generation of the benchmark (ARC-AGI-3), standard zero-shot LLMs perform poorly.

By plugging open-weights Qwen 30B into Cognithor's multi-agent code-generation and visual hypothesis verification pipeline, the framework successfully solved approximately 30% of ARC-AGI-3 tasks. This notably surpassed existing approaches from Claude with Opus 4.7, proving that an engineered agent harness and verification loop can dramatically amplify reasoning performance over raw model scale.
