Problem & Discovery

While preparing for IGCSE examinations, students were provided Pearson ActiveLearn digital textbooks locked behind a clunky web viewer with no native option to export or download offline copies for note-taking on tablets or offline study.

Inspecting the browser network traffic during page flipping revealed that individual high-resolution textbook pages were served directly from static CDN URLs using predictable naming patterns without authentication tokens or DRM encryption.

Engineering Solution

To automate what would otherwise be hundreds of manual browser clicks, I wrote a Python script utilizing a multi-threaded request pool. The pipeline:

  • Discovers book metadata and page counts from initial document manifest payloads.
  • Dispatches concurrent asynchronous workers to download page images in parallel with retry backoffs.
  • Validates image dimensions and byte streams for missing or corrupted chunks.
  • Merges sorted image buffers directly into a lossless, bookmarked PDF document using Pillow and PyPDF.
Early Engineering Journey

This project served as an early practical exploration into network inspection, reverse-engineering web endpoints, concurrency management in Python, and handling binary image streams.
