Research Motivation: Evaluating Upscaling Fidelity

For my International Baccalaureate Extended Essay (EE), I conducted an empirical investigation into real-time neural upscaling technologies, contrasting the temporal feedback network of NVIDIA DLSS against the spatial/temporal filters of AMD FSR.

Evaluating upscaled video games requires a no-reference image quality metric (since pristine native 4K ground truth rendered without temporal anti-aliasing can introduce its own artifacts). NIQE (Natural Image Quality Evaluator) is the academic benchmark for assessing naturalness using generalized Gaussian distributions of spatial domain features.

However, the original MATLAB and legacy Python implementations from 2014 were broken: abandoned dependencies, broken matrix math on modern NumPy, and lack of batch GPU support made them unusable in modern automated test pipelines.

Engineering Modernizations

Modernized Codebase Improvements

• Contemporary NumPy & SciPy Compatibility: Refactored legacy deprecated calls, eliminating float conversion warnings and matrix dimensionality mismatches.

• Accelerated Spatial Filtering: Reimplemented Mean Subtracted Contrast Normalized (MSCN) coefficient computations using modern OpenCV kernels for 5x faster batch evaluations.

• Clean CLI & Modular API: Packaged as a clean command-line utility and importable Python package for automated CI/CD and large-scale dataset benchmarking.
