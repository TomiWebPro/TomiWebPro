The idea

If you just bought a many-core monster, why stare at boring flat CPU graphs? This project treats the task manager's per-core load grid as a pixel canvas — idle cores draw white, pegged cores draw dark — so it renders letters and pixel art as live CPU load.

How it works

A Python script binarizes any image to pure black and white at the exact core-grid resolution and prints a brightness map. A small C program then launches one thread per logical core, pins each with an affinity mask, and either idles it or spins it in a busy loop — so the task manager paints the picture.
