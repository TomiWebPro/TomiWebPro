What it is

A local-first vocabulary drill tool: a master word list feeds a daily queue, and mastered items get archived to a learned list. Request N words, get N unique picks excluding what you already know; mark batches memorized to move them over, add words manually, and de-duplicate the master list.

How it evolved

Version 1 was a single CLI script picking random words from flat files. Version 2 split into a CLI toolkit with parallel TXT and JSON stores plus translators. Version 3 rebuilt the same workflow as a tkinter GUI hub — seven buttons launching pick, review, update, import, de-duplicate, and search windows.
