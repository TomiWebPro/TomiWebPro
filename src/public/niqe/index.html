Research Motivation: Evaluating Upscaling Fidelity

For his International Baccalaureate Extended Essay (EE), Tomi conducted an empirical investigation into real-time neural upscaling technologies, contrasting the temporal feedback networks of NVIDIA DLSS against the spatial/temporal filters of AMD FSR.

Evaluating upscaled gaming frames requires a no-reference image quality metric. NIQE is an established academic benchmark for assessing perceptual naturalness using generalized Gaussian distributions of spatial domain features.

However, the original 2014 MATLAB and Python implementations were abandoned, incompatible with modern NumPy/SciPy, and lacked batch execution support. Tomi modernized the entire library to support automated benchmark suites.

Engineering Modernizations

Key Codebase Upgrades

• Contemporary NumPy Compatibility: Refactored deprecated matrix manipulation functions and resolved floating-point precision issues.

• Accelerated MSCN Coefficient Extraction: Reimplemented Mean Subtracted Contrast Normalized coefficient computations using modern OpenCV kernels for 5x faster batch evaluations.

• Clean Modular CLI: Packaged as a clean CLI tool and importable Python module for continuous integration and large-scale dataset benchmarking.
