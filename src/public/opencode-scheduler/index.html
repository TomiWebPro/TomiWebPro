What it is

opencode-scheduler runs natural-language prompts as headless agent tasks on cron, interval, or one-shot schedules, with state in SQLite. Every run is verified, graded with a quality report ending in a score and verdict, and logged to a searchable journal — plus Gmail notifications and an email-to-task bridge that turns a self-sent email into a real scheduled job.

How a run works

Each job spawns opencode run under its timeout, then chains up to two more agent calls: a verifier that answers CHECK PASS or FAIL, and a reporter that writes the quality summary. Outputs land in per-run logs, the journal, and an activity stream, so everything the agents did, when, and how well is always traceable.
