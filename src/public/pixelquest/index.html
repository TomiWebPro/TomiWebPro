What it is

PixelQuest is a 2D pixel-art platformer with two handcrafted levels in forest and ember themes. The player runs, jumps, glides, sprints, dashes, and fights with a sword through enemies, crushers, moving platforms, switches, pressure plates, doors, keys, pickups, and secret gems — with perks, achievements, a local leaderboard, and rebindable controls plus touch support on mobile.

Genesis & Academic-Integrity Note

PixelQuest was built in November 2026 in a single overnight AI-assisted sprint as an architectural reference for a TUM Fundamentals of Programming team project. It was kept strictly separate from the group coursework submission to uphold academic integrity, with plans for a public App Store release.

How it's built

Built with libGDX 1.12.1 and Java 17 on Gradle, with shared code in core/ and separate launchers for desktop, Android, and iOS. All sprites, parallax backgrounds, sound effects, and music are generated procedurally in code — only level layouts ship as data files — and saves, settings, and progress persist as local JSON.
