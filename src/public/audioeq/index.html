The problem

Running Windows on MacBook hardware loses Apple's native macOS audio tuning, leaving the speakers sounding thin and wrong compared to macOS.

The fix

A ready-made 11-band correction curve — low-end lift, midrange dip, high-end shaping — shipped in two formats: a Peace preset and a FilterCurve file. Tuned on a 2019 13-inch MacBook Pro with four Thunderbolt ports; works on similar models.
