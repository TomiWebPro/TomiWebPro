Problem & Discovery

While preparing for IGCSE examinations, students were provided Pearson ActiveLearn digital textbooks locked behind a web viewer with no native option to export or download offline copies for tablet note-taking or offline study.

Inspecting browser network traffic during page flipping revealed that individual high-resolution textbook pages were served directly from static CDN URLs using predictable naming patterns without authentication barriers or encryption.

Tomi engineered a multi-threaded Python pipeline that parses book manifests, downloads pages concurrently, verifies byte integrity, and compiles them directly into a losslessly compressed PDF using Pillow and PyPDF.
